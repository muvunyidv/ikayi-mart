# IKAYIMART

Rwanda marketplace: guest shopper checkout and vendor management.

| Folder | Stack |
|---|---|
| `frontend/` | Flutter (web, Android, iOS, Windows, macOS) |
| `backend/` | NestJS + Prisma + PostgreSQL |

GitHub Pages deploys the Flutter web build from `frontend/` to [mart.ikayi.app](https://mart.ikayi.app).
